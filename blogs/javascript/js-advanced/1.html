策略模式 if-else 语句优化

用策略模式组织条件分支，让不断增长的 if-else 更容易维护。

JavaScript

# 简介

面向对象设计思想这块还是需要不断学习，策略模式是指 制定不同的运算策略（函数），赋给一个策略类对象，策略类中会去找对应的策略去实现方法，贴近面向对象的设计思想-解耦。

class Calculator {
   //  构造器
    constructor(){
        this.strategy= null; 
    }
    setStrategy(strategy){
        this.strategy = strategy; //内部的策略对象===传入的策略对象
    }
   // 灵魂 
    calculatorResult (num1,num2 ){ //传入的策略对象有execute方法
       return  this.strategy.execute(num1,num2);
    }
}

// 加减乘除四个策略类
class Add {
  execute(num1, num2) {
    return num1 + num2;
  }
}

class Sub {
  execute(num1, num2) {
    return num1 - num2;
  }
}

class Mul {
  execute(num1, num2) {
    return num1 * num2;
  }
}

class Div {
  execute(num1, num2) {
    return num1 / num2;
  }
}

let caluctor = new Calculator();
caluctor.setStrategy(new Add()); //传入不同的策略
console.log(caluctor.calculatorResult(6,3))//9
