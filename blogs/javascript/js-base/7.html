手写防抖节流

xijiajie 2022-03-14 JavaScript

# 防抖和节流怎么选

防抖关注“停下来以后再执行”，节流关注“持续触发时控制频率”。下面分别实现尾部执行的防抖和首次立即执行的节流，二者的最后一次调用行为不同。

场景 选择 行为
搜索框输入 防抖 停止输入 300ms 后，用最后一次输入发起查询
滚动时更新状态 节流 第一次立即执行，之后至少间隔 200ms 执行一次

它们只控制函数调用时机，不会自动取消已经发出的请求，也不能代替服务端的重复提交保护。

# 防抖：重新开始等待

每次调用先取消旧计时器，再开始新的等待。下面保留最后一次调用的参数和 this，并提供取消方法。

function debounce(fn, wait = 300) {
  if (typeof fn !== 'function') {
    throw new TypeError('fn 必须是函数');
  }
  let timer = null;

  function debounced(...args) {
    clearTimeout(timer);
    timer = setTimeout(() => {
      timer = null;
      Reflect.apply(fn, this, args);
    }, wait);
  }

  debounced.cancel = function () {
    clearTimeout(timer);
    timer = null;
  };
  return debounced;
}

如果在 0ms、100ms、200ms 各调用一次，等待时间为 300ms，则仅在约 500ms 执行最后一次调用。连续触发一直不停止，这个版本也会一直等待。

防抖函数不会同步返回原函数的计算结果，因为原函数要在计时器里执行。计时器的实际执行时间还受事件循环调度影响，并不保证精确到毫秒。

# 节流：达到间隔再执行

这里实现的是“首次立即执行、没有尾部补调用”的版本。窗口内被忽略的调用不会在窗口结束后自动执行。

function throttle(fn, wait = 200) {
  if (typeof fn !== 'function') {
    throw new TypeError('fn 必须是函数');
  }
  let lastCall = -Infinity;

  function throttled(...args) {
    const now = performance.now();
    if (now - lastCall >= wait) {
      lastCall = now;
      return Reflect.apply(fn, this, args);
    }
  }

  throttled.cancel = function () {
    lastCall = -Infinity;
  };
  return throttled;
}

使用单调时钟 performance.now() 测量间隔，避免系统时间校准影响判断；它返回的数值不是日期时间。可参见 MDN：performance.now。

lastCall 初始化为 -Infinity，保证第一次调用立即执行；使用 >=，让刚好到达间隔边界的调用也能执行。先更新时间再调用原函数，可以避免原函数同步再次调用包装函数时重复进入。

如果在 0ms、100ms、200ms、250ms 各调用一次，间隔为 200ms，则在 0ms 和 200ms 执行；250ms 的调用被忽略，400ms 不会自动补执行。如果业务需要最后一次事件也生效，例如保存最终滚动位置，需要额外实现尾部调用策略。

# 将包装函数接入事件监听

注册监听时要传入包装后的函数，并保存同一个引用供移除监听使用。

const input = document.querySelector('#search');
const onInput = debounce(function (event) {
  console.log('查询：', event.target.value);
}, 300);

const onScroll = throttle(function () {
  console.log('滚动位置：', window.scrollY);
}, 200);

// 确保页面已有 id="search" 的输入框。
input.addEventListener('input', onInput);
window.addEventListener('scroll', onScroll, { passive: true });

// 页面或组件销毁时调用，例如 Vue 的 beforeDestroy。
function dispose() {
  input.removeEventListener('input', onInput);
  window.removeEventListener('scroll', onScroll);
  onInput.cancel();
  onScroll.cancel();
}

不要在移除监听时重新调用 debounce 或 throttle，那会创建另一个函数，无法移除原来的监听。防抖的 cancel 会取消待执行任务；这个节流版本没有计时器，cancel 的作用是重置间隔，让下一次调用立即执行。
