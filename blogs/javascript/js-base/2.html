如何模拟实现一个 bind 的效果？

如何模拟实现一个 bind 的效果？

xijiajie 2021-12-12 JavaScript

# bind 的作用

bind 返回一个新函数，调用新函数时才执行原函数。它可以固定普通调用时的 this，并预先传入部分参数；调用时传入的参数接在预置参数后面。

如果通过 new 调用绑定函数，绑定的 this 会被忽略，预置参数仍然生效。原函数必须能够作为构造函数调用，详见 MDN：bind。

# 手写一个教学版本

下面使用独立的 bindFactory，避免覆盖 Function.prototype.bind。普通调用借助 Reflect.apply，构造调用借助 Reflect.construct，重点是理解两条调用路径。

function bindFactory(fn, context, ...presetArgs) {
  if (typeof fn !== 'function') {
    throw new TypeError('fn 必须是函数');
  }

  function bound(...args) {
    const allArgs = [...presetArgs, ...args];
    if (new.target) {
      return Reflect.construct(fn, allArgs, new.target);
    }
    return Reflect.apply(fn, context, allArgs);
  }

  const prototype = fn.prototype;
  if (prototype !== null &&
      (typeof prototype === 'object' || typeof prototype === 'function')) {
    bound.prototype = Object.create(prototype, {
      constructor: { value: bound, writable: true, configurable: true },
    });
  }
  return bound;
}

普通调用必须 return 原函数的结果，否则计算、对象创建等场景会得到 undefined。原型应赋给 bound.prototype，不能将 bound 本身替换成一个普通对象。

function sum(a, b) {
  return this.base + a + b;
}

const add = bindFactory(sum, { base: 10 }, 2);
console.log(add(3)); // 15
console.log(add.call({ base: 100 }, 3)); // 15，普通调用的 this 已固定

function Person(name, age) {
  this.name = name;
  this.age = age;
}
Person.prototype.say = function () {
  return this.name;
};

const receiver = { name: '不会被修改' };
const BoundPerson = bindFactory(Person, receiver, '小明');
const person = new BoundPerson(18);
console.log(person.say()); // 小明
console.log(person.age); // 18
console.log(person instanceof Person); // true
console.log(person instanceof BoundPerson); // true
console.log(receiver.name); // 不会被修改

# 与原生 bind 的差异

这个版本保留了普通调用的返回值，也能处理普通构造函数和 class 的构造调用，但不等同于原生绑定函数：

  • 原生绑定函数没有自己的 prototype 属性；这里为了演示继承关系创建了该属性。
  • 这里构造出的对象多一层 bound.prototype，原生绑定函数的 instanceof 判断会转交给目标函数。
  • 直接 new 原生绑定函数时，目标函数看到的 new.target 是原函数；这里是 bound。
  • 没有完整模拟原生函数的 name、length 等属性，以及再次绑定已有绑定函数时的构造语义。

生产代码优先使用原生 fn.bind(context, ...args)。箭头函数的 this 由定义位置决定，bind 无法改变它；绑定箭头函数后也不能通过 new 创建实例。
